# Perceptron-Based Iris Classification

## 📌 Overview

This project implements **Iris Flower Classification** using the **Perceptron Algorithm**, one of the simplest supervised machine learning algorithms used for binary and multiclass classification. The model learns from the Iris dataset and classifies flowers into one of the three species based on their sepal and petal measurements.

---

## 🎯 Objective

- To implement the Perceptron algorithm for Iris flower classification.
- To train the model using the Iris dataset.
- To classify Iris flowers into different species.
- To evaluate the performance of the Perceptron classifier.

---

## 📂 Dataset

The project uses the **Iris Dataset**, which contains 150 flower samples with the following features:

- Sepal Length (cm)
- Sepal Width (cm)
- Petal Length (cm)
- Petal Width (cm)

### Target Classes

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## 📚 Machine Learning Algorithm

This project uses the **Perceptron Classifier**, a linear classification algorithm that learns by updating weights based on classification errors during training. It is suitable for solving linearly separable classification problems.

---

## ⚙️ Steps Performed

1. Import the required libraries.
2. Load the Iris dataset.
3. Explore and preprocess the dataset.
4. Split the dataset into training and testing sets.
5. Train the Perceptron classifier.
6. Predict the Iris flower species.
7. Evaluate the model using classification metrics.
8. Display the prediction results.
