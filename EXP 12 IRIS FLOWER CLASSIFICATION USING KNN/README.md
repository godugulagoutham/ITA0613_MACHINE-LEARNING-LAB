# Iris Flower Classification using K-Nearest Neighbors (KNN)

## 📌 Overview

This project implements the **Iris Flower Classification** problem using the **K-Nearest Neighbors (KNN)** algorithm. The model classifies Iris flowers into one of the three species—Setosa, Versicolor, or Virginica—based on the measurements of their sepal and petal dimensions.

---

## 🎯 Objective

- To implement the K-Nearest Neighbors (KNN) classification algorithm.
- To classify Iris flower species using their physical characteristics.
- To evaluate the performance of the KNN model using appropriate metrics.

---

## 📂 Dataset

The project uses the famous **Iris Dataset**, which contains 150 flower samples with the following features:

- Sepal Length (cm)
- Sepal Width (cm)
- Petal Length (cm)
- Petal Width (cm)

### Target Classes

- Iris Setosa
- Iris Versicolor
- Iris Virginica

---

## 🛠️ Technologies Used

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📚 Machine Learning Algorithm

The **K-Nearest Neighbors (KNN)** algorithm is used for classification. It predicts the class of a new flower by finding the K nearest training samples based on distance and assigning the majority class among them.
