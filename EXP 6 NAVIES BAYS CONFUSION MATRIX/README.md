# 🤖 Experiment 6: Naïve Bayes Classification

## 📌 Objective

To implement the **Naïve Bayes Algorithm** in Python and evaluate its performance using a confusion matrix and accuracy score.

---

## 📖 Description

Naïve Bayes is a supervised machine learning algorithm based on **Bayes' Theorem**. It is widely used for classification tasks because of its simplicity and efficiency. The algorithm assumes that all features are independent of each other, making it suitable for problems such as spam detection, sentiment analysis, and document classification.

---

## 🎯 Aim

To implement the Naïve Bayes classification algorithm in Python and evaluate the model using a confusion matrix and accuracy score.

---

## 💻 Software Required

- Google Colab
- Python
- Pandas
- NumPy
- Scikit-learn

---

## 🔄 Procedure

1. Open Google Colab and import the required Python libraries.
2. Load the dataset and preprocess the data.
3. Split the dataset into training and testing sets.
4. Train the Naïve Bayes classifier using the training data.
5. Predict the class labels for the testing data.
6. Generate the confusion matrix and calculate the accuracy score.
7. Display the classification results.
