# 📊 Experiment 7: Logistic Regression Algorithm

## 📌 Objective

To implement the **Logistic Regression Algorithm** in Python and classify data using a suitable dataset.

---

## 📖 Description

Logistic Regression is a supervised machine learning algorithm used for classification problems. It predicts the probability of a data point belonging to a particular class using the sigmoid function. It is commonly used for binary classification tasks such as disease prediction, spam detection, and customer churn analysis.

---

## 🎯 Aim

To implement the Logistic Regression algorithm in Python and evaluate its performance using a suitable dataset.

---
