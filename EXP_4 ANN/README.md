# 🧠 Experiment 4: Artificial Neural Network using Backpropagation Algorithm

## 📌 Objective

To build an Artificial Neural Network (ANN) by implementing the **Backpropagation Algorithm** and test its performance using an appropriate dataset.

---

## 📖 Description

Artificial Neural Networks (ANNs) are machine learning models inspired by the structure and functioning of the human brain. The **Backpropagation Algorithm** is a supervised learning algorithm used to train neural networks by minimizing the error between the predicted output and the actual output. It updates the weights of the network through gradient descent, improving prediction accuracy over multiple iterations.

---

## 🎯 Aim

To implement an Artificial Neural Network using the Backpropagation Algorithm in Python and evaluate its performance using a suitable dataset.

## 📚 Theory

An Artificial Neural Network consists of interconnected neurons arranged in input, hidden, and output layers. During training, the network performs a forward pass to generate predictions and then computes the error between the predicted and actual outputs. The Backpropagation Algorithm propagates this error backward through the network and updates the weights using gradient descent to reduce the prediction error. This process is repeated for several epochs until the model achieves satisfactory performance.
