# A–G Task Output Results

All results below were generated by the single interlinked `main.py` pipeline.
The current dataset is a reproducibility benchmark and must be replaced by the required public dataset before academic submission.

## Task A — Data Engineering & EDA

**Result:** Processed 20,000 rows; cleaned 20,000 rows. Created GDD, rainfall anomaly, temperature range and heat-stress features. Time split: 16,743 train, 1,583 validation, 1,674 test.

**Generated outputs:**
- `tables/cleaned_engineered_data.csv`
- `plots/01_rainfall_vs_yield.png`
- `plots/02_average_yield_by_crop.png`
- `plots/03_yield_trend.png`
- `plots/04_feature_correlation.png`

## Task B — kNN Regression

**Result:** Best validation configuration: mahalanobis distance with k=21. Test MAE=1.3640, RMSE=1.8182, R²=-0.0191.

**Generated outputs:**
- `tables/knn_validation.csv`
- `tables/knn_test_results.csv`
- `tables/knn_predictions.csv`
- `plots/05_knn_validation_curve.png`

## Task C — Locally Weighted Regression

**Result:** Best validation bandwidth: tau=2.0. Test MAE=1.3546, RMSE=1.8201, R²=-0.0212. LWR uses a bounded 200-neighbour local fit for computational feasibility.

**Generated outputs:**
- `tables/lwr_validation.csv`
- `tables/lwr_test_results.csv`
- `tables/lwr_predictions.csv`
- `plots/06_lwr_validation_curve.png`

## Task D — Candidate-Elimination / Version Space

**Result:** Yield was discretised into Low/Medium/High risk bands and Candidate-Elimination updates were recorded as specific/general boundary states.

**Generated outputs:**
- `tables/candidate_elimination_history.csv`
