# 📊 Experiment 10: Expectation Maximization (EM) Algorithm

## 📌 Objective

---

## 📖 Description

The Expectation Maximization (EM) Algorithm is an unsupervised machine learning algorithm used to estimate the parameters of statistical models with hidden variables. It is commonly used for clustering through Gaussian Mixture Models (GMM). The algorithm iteratively performs the Expectation (E) step and the Maximization (M) step until convergence.

## ✅ Advantages

- Handles overlapping clusters effectively.
- Provides probabilistic cluster assignments.
- Suitable for complex data distributions.
- Works well with Gaussian Mixture Models.

---

## ❌ Limitations

- Computationally expensive for large datasets.
- Sensitive to initialization.
- May converge to a local optimum.
- Assumes data follows a Gaussian distribution.
