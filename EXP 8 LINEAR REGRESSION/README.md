# 📈 Experiment 8: Linear Regression Algorithm

## 📌 Objective

To implement the **Linear Regression Algorithm** in Python and predict continuous values using a suitable dataset.

---

## 📖 Description

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values. It establishes a linear relationship between the independent variables (features) and the dependent variable (target). The algorithm finds the best-fit line that minimizes the prediction error and is widely used for forecasting and trend analysis.

---

## 🎯 Aim

To implement the Linear Regression algorithm in Python and predict continuous values using a suitable dataset.

---

## 💻 Software Required

- Google Colab
- Python
- Pandas
- NumPy
- Scikit-learn

---

## 🔄 Procedure

1. Open Google Colab and import the required Python libraries.
2. Load the dataset and preprocess the data.
3. Split the dataset into training and testing sets.
4. Train the Linear Regression model using the training data.
5. Predict the target values for the testing data.
6. Evaluate the model using performance metrics such as Mean Squared Error (MSE) and R² Score.
7. Display the prediction results and regression line.
