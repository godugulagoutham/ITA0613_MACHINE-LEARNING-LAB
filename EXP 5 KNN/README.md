# 🤖 Experiment 5: K-Nearest Neighbours (K-NN) Algorithm

## 📌 Objective

To implement the **K-Nearest Neighbours (K-NN) Algorithm** in Python and classify data points based on the nearest neighbors.

---

## 📖 Description

K-Nearest Neighbours (K-NN) is a supervised machine learning algorithm used for classification and regression tasks. It classifies a new data point by identifying the **K** closest training samples based on a distance metric such as Euclidean distance. The new data point is assigned to the class that is most common among its nearest neighbors.

---

## 🎯 Aim

To implement the K-Nearest Neighbours (K-NN) Algorithm in Python and classify data points using the given dataset.
