# Iris Flower Classification using Naive Bayes Classifier

## 📌 Overview

This project implements **Iris Flower Classification** using the **Naive Bayes Classifier**. The objective is to classify Iris flowers into one of the three species—Setosa, Versicolor, or Virginica—based on their sepal and petal measurements. Naive Bayes is a probabilistic machine learning algorithm that applies Bayes' Theorem with the assumption that features are independent.

---

## 🎯 Objective

- To implement the Naive Bayes classification algorithm.
- To classify Iris flower species based on their physical measurements.
- To train and evaluate the model using the Iris dataset.
- To analyze the classification performance using standard evaluation metrics.

---

## 📂 Dataset

The project uses the **Iris Dataset**, which contains 150 flower samples with the following features:

- Sepal Length (cm)
- Sepal Width (cm)
- Petal Length (cm)
- Petal Width (cm)

### Target Classes

- Iris Setosa
- Iris Versicolor
- Iris Virginica

---

## 🛠️ Technologies Used

- Python 3.x
- Pandas

---

## 📚 Machine Learning Algorithm

This project uses the **Gaussian Naive Bayes (GaussianNB)** algorithm. It predicts the species of an Iris flower by calculating the probability of each class using Bayes' Theorem and selecting the class with the highest probability.

---

## ⚙️ Steps Performed

1. Import the required libraries.
2. Load the Iris dataset.
3. Explore and visualize the dataset.
4. Split the dataset into training and testing sets.
5. Train the Gaussian Naive Bayes classifier.
6. Predict the flower species.
7. Evaluate the model performance.
8. Display the classification results.
