# Future Sales Prediction using Machine Learning

## 📌 Overview

This project implements a **Future Sales Prediction** model using Machine Learning. The objective is to forecast future sales based on historical sales data, product information, and market trends. The model helps businesses estimate future demand, optimize inventory, and make informed business decisions.

---

## 🎯 Objective

- To develop a machine learning model for future sales prediction.
- To analyze historical sales data and identify trends.
- To train and evaluate a regression model for forecasting future sales.
- To predict future sales for better business planning.

---

## 📂 Dataset

The dataset contains historical sales records, including:

- Date
- Store ID
- Item ID
- Product Category
- Product Name
- Item Price
- Number of Items Sold
- Monthly Sales
- Customer Information (if available)
- Future Sales (Target)

---

## 🛠️ Technologies Used

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📚 Machine Learning Algorithm

This project uses a **Random Forest Regressor** (or any suitable regression algorithm such as Linear Regression, Decision Tree Regressor, or XGBoost Regressor) to predict future sales based on historical sales data.

---

## ⚙️ Steps Performed

1. Import the required libraries.
2. Load the historical sales dataset.
3. Explore and preprocess the dataset.
4. Handle missing values and prepare features.
5. Split the dataset into training and testing sets.
6. Train the regression model.
7. Predict future sales.
8. Evaluate the model using regression metrics.
9. Visualize the predicted sales against actual sales.

---

## 📊 Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
