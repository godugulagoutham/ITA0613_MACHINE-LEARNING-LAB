# 📊 Experiment 9: Comparison of Linear and Polynomial Regression

## 📌 Objective

To implement and compare **Linear Regression** and **Polynomial Regression** using Python and evaluate their performance on a given dataset.

---

## 📖 Description

Linear Regression and Polynomial Regression are supervised machine learning algorithms used for predicting continuous values. Linear Regression models a linear relationship between the input features and the target variable, whereas Polynomial Regression models non-linear relationships by introducing polynomial features. This experiment compares both algorithms to determine which model better fits the given dataset.

---

## 🎯 Aim

To implement Linear Regression and Polynomial Regression using Python and compare their performance on a given dataset.

---

## 💻 Software Required

- Google Colab
- Python
- Pandas
- NumPy
- Scikit-learn

---

## 🔄 Procedure

1. Open Google Colab and import the required Python libraries.
2. Load and preprocess the dataset.
3. Split the dataset into training and testing sets.
4. Train the Linear Regression model using the training data.
5. Transform the features into polynomial features and train the Polynomial Regression model.
6. Predict the output using both models.
7. Compare the performance of both models using evaluation metrics and visualize the results.

---

## 📂 Input

A dataset containing:

- Independent Variables (Features)
- Dependent Variable (Target)

Example:
- Salary Dataset
- House Price Dataset

## ✅ Advantages

- Easy to compare different regression models.
- Polynomial Regression captures non-linear relationships.
- Improves prediction accuracy for complex datasets.
- Useful for selecting the best regression model.

---

## ❌ Limitations

- Linear Regression performs poorly on non-linear data.
- Polynomial Regression may overfit the training data.
- Requires proper selection of polynomial degree.
- Sensitive to outliers.

---

## 📈 Expected Result

The Linear Regression and Polynomial Regression models are successfully implemented and compared. Polynomial Regression generally provides better performance for datasets with non-linear relationships.

---

## 🏁 Conclusion

The experiment successfully implemented and compared Linear Regression and Polynomial Regression using Python. The comparison showed that Linear Regression is suitable for linear datasets, while Polynomial Regression provides better accuracy for non-linear datasets, depending on the nature of the data.
