# Naive Bayes Classification for Bank Loan Prediction

## 📌 Overview

This project implements **Bank Loan Prediction** using the **Naive Bayes Classification** algorithm. The objective is to predict whether a loan application should be approved based on customer information such as income, education, employment status, credit history, and loan amount. The model helps financial institutions automate the loan approval process efficiently.

---

## 🎯 Objective

- To implement the Naive Bayes classification algorithm for bank loan prediction.
- To preprocess and analyze the loan dataset.
- To classify loan applications as approved or rejected.
- To evaluate the performance of the classification model.

---

## 📂 Dataset

The dataset contains customer and loan-related information, including:

- Gender
- Marital Status
- Number of Dependents
- Education
- Self Employed
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area
- Loan Status (Target)

---

## 🛠️ Technologies Used

- Python 3.x

- Scikit-learn

---

## 📚 Machine Learning Algorithm

This project uses the **Gaussian Naive Bayes (GaussianNB)** algorithm to classify loan applications. The algorithm predicts whether a customer is eligible for a loan based on the probability of the input features using Bayes' Theorem.

---

## ⚙️ Steps Performed

1. Import the required libraries.
2. Load the bank loan dataset.
3. Explore and preprocess the dataset.
4. Handle missing values.
5. Encode categorical variables.
6. Split the dataset into training and testing sets.
7. Train the Naive Bayes classifier.
8. Predict the loan approval status.
9. Evaluate the model using classification metrics.
10. Display the prediction results.

---
