# Car Price Prediction using Machine Learning

## 📌 Overview

This project implements a **Car Price Prediction** model using Machine Learning. The objective is to predict the selling price of a car based on various features such as the car's brand, model, manufacturing year, fuel type, transmission type, kilometers driven, and other specifications. The model helps estimate a fair market value for used cars.

---

## 🎯 Objective

- To build a machine learning model for predicting car prices.
- To preprocess and analyze the car dataset.
- To train and evaluate a regression model.
- To predict the selling price of a car based on its features.

---

## 📂 Dataset

The dataset contains information about used cars, including:

- Car Name
- Year of Manufacture
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner
- Selling Price (Target)

---

## 🛠️ Technologies Used

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📚 Machine Learning Algorithm

This project uses a **Linear Regression** model (or any suitable regression algorithm such as Random Forest Regressor) to predict the selling price of cars based on the input features.

---

## ⚙️ Steps Performed

1. Import the required libraries.
2. Load the car price dataset.
3. Explore and analyze the dataset.
4. Handle missing values.
5. Encode categorical features.
6. Split the dataset into training and testing sets.
7. Train the regression model.
8. Predict the selling price.
9. Evaluate the model performance.
10. Display the prediction results.

---

## 📊 Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
